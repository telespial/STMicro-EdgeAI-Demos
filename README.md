# STMicroelectronics EdgeAI Demos

This repository currently contains the [Smart Pong](./smart-pong) demonstration. Its README and `start_here.md` provide the project-specific setup and usage information; no additional board, measurement, or deployment claims are made here.

See [LICENSE](./LICENSE) for license terms.

## How the example relates

Smart Pong documents adaptive predictor behavior alongside human control and a fixed classic predictor on STM32H7S78-DK. It is a demonstration, not a claim of production readiness. See the [EIL specification](https://github.com/telespial/Embedded-Intelligence-Layer-Specs) for the bounded-runtime concept and the [EmbeddedX index](https://github.com/telespial/EmbeddedX-Specs) for related specifications.
